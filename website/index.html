Built for Data Integrity

Prepix replaces repetitive inspection scripts with standardized, hardened quality routines.

🛡️

DataFrame Immutability

Zero in-place mutations. Your original DataFrame is never altered, index values are never modified, and columns are never silently cast.

📊

Unified Quality Report

Execute pp.report(df) to instantly generate a consolidated multi-dimensional health overview, prioritized issues, and component sub-reports.

🔍

Schema Contract Audits

Verify column presence, expected dtypes, nullability constraints, and uniqueness against your schema before running downstream models.

📈

Distribution Diagnostics

Calculate 5-number summaries, sample standard deviations, IQR, Fisher-Pearson skewness, kurtosis, zero/negative counts, and Tukey outliers.

🏷️

Cardinality Classification

Automatically categorize columns across six cardinality tiers, detecting constant columns (zero variance) and primary key identifiers.

⚙️

Zero Heavy Dependencies

Built strictly on top of pandas>=2.0.0 and numpy>=1.24.0. No heavy runtimes or bulky web servers required.

API Function Reference

Complete signatures, parameter options, return structures, and examples for all 7 public functions.

pp.report(df, ...)

Unified Diagnosis

Produces a comprehensive dataset health diagnosis combining dimensions, memory, missingness, duplicate rows, cardinality, numerical distributions, prioritized findings, and actionable recommendations. 

import prepix as pp
import pandas as pd

df = pd.read_csv("data.csv")
report = pp.report(df)

# Print human-readable summary
print(report)

# Access granular components:
print(report.overview)
print(report.issues)
print(report.missing)
print(report.numeric)

pp.missing_report(df, low_threshold=10.0, medium_threshold=30.0, only_missing=False)

Missing Values

Calculates missing values count and percentage per column, categorizing missingness into severity tiers with conservative imputation suggestions.

missing_report Example 
# Audit only columns that contain missing values
missing = pp.missing_report(df, only_missing=True)
print(missing)
# Output columns: Column, Missing Values, Missing Percentage(%), Status, Suggestion

pp.column_summary(df, dropna=True)

Structural Profiling

Profiles every column's data type, missing counts, unique values, deep RAM footprint, and semantic suggested type (Binary, Numeric, Categorical, Datetime).

column_summary Example 
summary = pp.column_summary(df)
print(summary[["Column", "Data Type", "Unique Values", "Memory(Bytes)", "Suggested Type"]])

pp.duplicate_report(df, subset=None, keep='first', return_records=False)

Duplicate Detection

Detects duplicate rows across the entire dataset or specific key subsets, or returns duplicate records directly with return_records=True.

duplicate_report Example 
# 1. Summary report
print(pp.duplicate_report(df))

# 2. Extract duplicate records directly for inspection:
dups = pp.duplicate_report(df, return_records=True)
print(dups)

pp.unique_report(df, dropna=False)

Cardinality Audit

Audits column cardinality into six standardized tiers (Constant, Low, Medium, High, Very High, Very High (Unique)), flagging zero-variance features and candidate identifiers.

unique_report Example 
unique_profile = pp.unique_report(df)
print(unique_profile[["Column", "Unique Values", "Cardinality", "Status", "Suggestion"]])

pp.numeric_summary(df, extended=False, percentiles=None)

Numeric Statistics

Computes 5-number summaries, mean, sample standard deviation, and optional distribution diagnostics: IQR, Fisher-Pearson skewness, kurtosis, zero/negative counts, and Tukey 1.5x IQR outliers.

numeric_summary Example 
# Extended statistics with 1st and 99th percentiles
num_stats = pp.numeric_summary(df, extended=True, percentiles=[0.01, 0.99])
print(num_stats[["Column", "Mean", "Median", "IQR", "Skewness", "Outliers", "P1", "P99"]])

pp.schema_report(df, schema, allow_unexpected=True)

Schema Validation

Enforces data contracts by validating column presence, expected types, nullability, uniqueness, and unexpected columns.

schema_report Example 
schema = {
    "ID": {"type": "integer", "nullable": False, "unique": True},
    "Name": "string",
    "Salary": {"type": "numeric", "nullable": False},
}
validation = pp.schema_report(df, schema=schema, allow_unexpected=False)
print(validation[["Column", "Check", "Status", "Message"]])
